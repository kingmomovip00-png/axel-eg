AXEL V11
- لوحة التحكم: نفس النسخة العاملة بدون تعديل على ملفاتها.
- صور المنتجات: contain داخل إطار ثابت لمنع القص/التشويه.
- الجريد الثاني يظهر دائماً، ويستخدم الأنمي إن وُجد وإلا مجموعة مختلفة من المنتجات.
- صفحة الدفع في منتصف الشاشة على الهاتف والكمبيوتر.
- اختيارات دفع واضحة مع علامات Visa / Mastercard / Meeza / Paymob وVodafone Cash وInstaPay.
- Paymob الحقيقي: Intention API + Unified Checkout + Webhook/HMAC. يلزم فقط إضافة بيانات Paymob الحقيقية في Bonto.
- الملفات الثابتة تعيد التحقق من الكاش، لذلك استبدال صورة بنفس الاسم لا يظل عالقاً في كاش الهاتف.
